# 이진분류 epoch 실험 수정 전 코드 기록

사용자 요청에 따라 이전 소스의 모든 줄을 `# `로 주석 처리해 보존했습니다.
이 폴더의 Python 파일은 기록용이며 실행하거나 import할 코드가 없습니다.

- `local/`: 수정 전 로컬 코드. 기존 주석까지 그대로 포함합니다.
- `github/`: GitHub commit `6105e71191aa85fd57bdf9901f0f074109ba0998`의
  이진분류 회복 코드와 10클래스 실험 코드 사본입니다.
- `manifest.json`: 원본 경로와 원본 파일 바이트의 SHA256입니다.

수정 시작 때 확인한 원격 HEAD는 `578ddbe9fd548da3d2f87109b532afeb2f0d3d17`입니다.
그 커밋은 10클래스 실험 결과만 추가했으며 위 소스 코드는 변경하지 않았습니다.
10클래스의 완전한 실행 코드와 결과는 해당 GitHub 커밋에 보존되어 있습니다.
이 폴더는 변경 사항을 이해하기 위한 기록이며 전체 저장소 백업은 아닙니다.

활성 실험은 프로젝트 루트의 `recovery_experiment.py`입니다.
현재 단계는 MNIST 3·8, 2색, epoch별 평가이며 step별 평가는 추가하지 않았습니다.
