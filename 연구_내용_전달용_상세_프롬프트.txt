연구 내용 전달용 상세 프롬프트

너는 머신러닝 실험 설계와 결과 해석을 돕는 연구 조력자다. 아래 내용을 바탕으로 내가 진행 중인 연구를 이해하고, 연구 내용을 설명하거나 후속 실험을 제안해줘.

실제로 완료한 작업, 관측된 결과, 해석, 앞으로 검증할 가설을 명확하게 구분해줘. 아직 수행하지 않은 실험의 결과를 만들어내거나, 현재 결과만으로 입증하지 못한 내용을 확정적으로 표현하지 마.

1. 연구 주제와 핵심 문제
============================================================

현재 연구는 숫자와 색상 사이에 인위적인 상관관계를 부여한 Colored MNIST를 이용하여, CNN이 색상이라는 지름길 특징에 얼마나 의존하는지 분석하는 연구다.

연구 주제를 설명하는 잠정적인 제목은 다음과 같다.
“색상 편향이 있는 Colored MNIST에서 CNN의 지름길 학습과 색상 의존성 분석”

모델이 수행해야 하는 과제는 이미지 속 숫자를 분류하는 것이다. 정답은 숫자의 모양으로 결정되며, 숫자의 색을 바꾸더라도 정답은 그대로 유지된다.

하지만 학습 데이터에서 특정 숫자가 거의 항상 특정 색으로 나타나면, 모델은 숫자의 모양을 충분히 구분하지 않고도 색을 이용해 높은 정확도를 얻을 수 있다.

이 연구에서는 다음 용어를 사용한다.
- 지름길 학습(shortcut learning): 학습 환경에서 예측에 유리한 단서를 이용하지만, 그 단서와 정답의 관계가 달라지면 성능이 크게 떨어지는 학습 양상.
- 허위 특징(spurious feature): 현재 실험에서는 정답을 정의하지 않으면서 학습 데이터에서 정답과 강하게 연결된 색상.
- 색상 편향: 숫자별로 특정 색상이 압도적으로 자주 나타나도록 만든 데이터 구성.

현재 확인하려는 핵심 질문은 다음과 같다.
“숫자와 색상이 약 99% 일치하는 데이터로 CNN을 짧게 학습시키면, 동일한 숫자 이미지의 색상만 변경했을 때 예측이 얼마나 달라지는가?”

추가로, 코드에는 중립 데이터와 회복 지표를 위한 준비가 들어 있다. 이를 바탕으로 향후에는 편향 학습 이후 색상 의존성을 줄이는 회복 과정을 연구할 수 있다. 다만 현재까지 중립 데이터로 회복 학습을 수행한 결과는 없다.

2. 현재 연구 범위와 초기 구현의 관계
============================================================

프로젝트에는 숫자 0~9와 10가지 색상을 사용하는 초기 Colored MNIST 구현이 남아 있다.

현재 활성화된 주요 실험은 다음과 같이 범위를 제한한다.
- 숫자: 3과 8
- 분류 클래스: 2개
- 색상: 2개
- 주요 모델: BinarySmallCNN
- 편향 강도: p = 0.99
- 주요 파일럿 학습량: 정확히 1 epoch
- 기본 seed: 42

숫자 3과 8만 사용하는 현재 설정에서는, 같은 숫자에 두 가지 색을 각각 적용해 결과를 직접 비교할 수 있다.

초기 10클래스 코드와 현재 2클래스 실험은 구분해서 설명해야 한다. 특히 현재 결과를 숫자 0~9 전체에 대한 결과로 소개해서는 안 된다.

3. 데이터 구성과 분할
============================================================

원본 데이터는 MNIST이며, 숫자 3과 8에 해당하는 이미지만 선택한다.

현재 데이터 구성은 다음과 같다.
- 공식 MNIST train 중 숫자 3·8: 11,982개
- 실제 학습용 train: 9,586개
- validation: 2,396개
- 공식 MNIST test 중 숫자 3·8: 1,984개

공식 train에서 선택한 11,982개를 seed=42로 약 80:20 무작위 분할한다. 클래스별 비율을 정확히 맞추는 층화 분할은 아니다.

분할 후 숫자별 개수는 다음과 같다.
- 숫자 3: train 4,923개, validation 1,208개
- 숫자 8: train 4,663개, validation 1,188개

원본 이미지 인덱스를 확인했을 때 train과 validation은 서로 겹치지 않는다.

모델에 사용하는 정답 target은 다음과 같이 변환한다.
- 숫자 3 → target 0
- 숫자 8 → target 1

이때 숫자 라벨, 모델 target, 색상 ID는 서로 다른 개념이다. 예를 들어 숫자 3 이미지가 반대 색을 받더라도 정답 target은 계속 0이다.

공식 test는 현재 주요 파일럿에서 학습이나 성능 평가에 사용하지 않고 최종 평가용으로 남겨둔다. 따라서 아래에 제시하는 주요 정확도는 validation 결과다.

4. 색상 생성 방식
============================================================

원본 MNIST 이미지는 [1, 28, 28] 형태의 흑백 텐서다. 여기에 RGB 색상을 곱해 [3, 28, 28] 형태로 변환한다.

색상 ID와 기본 Hue는 다음과 같다.
- 색상 ID 3: 기본 Hue 108°, 초록 계열
- 색상 ID 8: 기본 Hue 288°, 보라 계열

각 원본 이미지에는 작은 Hue 변화량 δ를 한 번 생성하여 고정한다.
- δ의 분포: Uniform(-5°, +5°)
- 실제 Hue: H = (36° × color_id + δ) mod 360°
- 색상 기준 RGB 생성 시 HSV의 Saturation과 Value는 각각 1
- 최종 이미지는 원본 흑백 픽셀값에 해당 RGB를 곱해 생성

이 방식은 숫자의 획과 원본 픽셀 강도에 따른 구조를 유지하면서 색상을 부여한다. 배경의 0인 픽셀은 검은색으로 유지된다. 여기서 밝기 유지란 구현상 원본 픽셀 강도와 HSV Value에 관한 것이며, 두 색의 지각적 밝기가 정확히 같다는 의미는 아니다.

재현성과 조건 통제를 위해 다음 원칙을 적용한다.
1) 색상 배정은 epoch마다 새로 추출하지 않는다.
2) Hue offset도 epoch마다 바뀌지 않는다.
3) 같은 원본 이미지에는 항상 같은 δ를 사용한다.
4) validation에서 색을 바꿔 비교할 때도 원본 이미지와 δ는 그대로 유지한다.
5) 원본 MNIST 인덱스를 기준으로 δ를 관리한다.

따라서 두 평가 조건 사이에서 달라지는 핵심 요소는 색상 ID다.

5. 편향 데이터와 중립 데이터
============================================================

5.1. 편향 데이터

학습 데이터에서는 다음 관계를 설정한다.
- P(color=3 | digit=3) ≈ 0.99
- P(color=8 | digit=8) ≈ 0.99

즉, 숫자 3은 대부분 초록 계열이고, 숫자 8은 대부분 보라 계열이다. 약 1%의 표본에는 반대 색상을 적용한다.

다음 두 조건을 구분한다.
- Aligned: 숫자 3에 color 3, 숫자 8에 color 8
- Conflict: 숫자 3에 color 8, 숫자 8에 color 3

색상이 다르더라도 숫자 정답에는 변화가 없다. 이 실험은 정답 라벨을 뒤집는 실험이 아니다.

현재 학습 데이터의 실제 구성은 다음과 같다.
- Aligned: 9,490개
- Conflict: 96개
- 실제 aligned 비율: 약 98.9985%
- 숫자와 색상의 이진 phi 상관계수: 약 0.979956

각 숫자 클래스에서 round(클래스 표본 수 × p)개를 aligned로 배정하므로, 실제 비율은 정확히 99%와 조금 다를 수 있다.

5.2. 중립 데이터

중립 조건에서는 각 숫자 안에서 두 색상이 약 50:50으로 나타나도록 배정한다.
- P(color=3 | digit=3) ≈ 0.5
- P(color=8 | digit=3) ≈ 0.5
- P(color=3 | digit=8) ≈ 0.5
- P(color=8 | digit=8) ≈ 0.5

현재 생성된 중립 배정의 phi 상관계수는 약 -0.0000057로, 0에 매우 가깝다.

중립 색상 배정 생성과 저장 기능은 구현되어 있다. 그러나 중립 배정을 저장했다는 사실과 중립 데이터로 모델을 학습했다는 사실은 구분해야 한다. 현재 파일럿은 편향 데이터로만 학습한다.

6. 모델 구조와 학습 설정
============================================================

현재 주요 모델은 BinarySmallCNN이다.

구조는 다음과 같다.

입력: RGB 3 × 28 × 28
    ↓
Conv2d: 3 → 16, kernel=3, padding=1
ReLU
MaxPool2d: 2
    ↓
16 × 14 × 14
    ↓
Conv2d: 16 → 32, kernel=3, padding=1
ReLU
MaxPool2d: 2
    ↓
32 × 7 × 7
    ↓
Flatten: 1,568개 특징
    ↓
Linear: 1,568 → 2
    ↓
숫자 3·8에 대한 logits

현재 모델에는 1,568개 특징과 최종 출력 사이에 별도의 64차원 은닉층이 없다.

학습 설정은 다음과 같다.
- 모델: BinarySmallCNN
- Optimizer: Adam
- Learning rate: 0.001
- Loss: CrossEntropyLoss
- Batch size: 64
- Seed: 42
- 편향 강도: p=0.99
- 파일럿 학습량: 1 epoch
- 저장된 주요 실행의 장치: CPU

pilot.py는 반복문으로 여러 epoch를 학습하는 방식이 아니라, 정확히 한 번의 epoch 학습을 실행한다.

별도의 train_cnn.py는 여러 epoch 실행을 지원하지만, 현재 확인된 해당 결과 파일들도 1 epoch 실행 기록이다. 코드의 기본 epoch 값과 실제 저장된 실험의 epoch를 혼동하지 않아야 한다.

Train Accuracy는 학습 중 각 배치에서 계산한 정확도를 누적한 값이다. 학습을 마친 최종 모델로 전체 train을 다시 평가한 정확도와는 구분한다.

7. 평가 설계와 지표
============================================================

validation의 원본 2,396개 각각에 대해 다음 두 버전을 만든다.
1) 학습 시의 주된 숫자·색상 관계를 따르는 aligned 이미지
2) 반대 색상을 적용한 conflict 이미지

두 조건은 같은 원본 이미지, 같은 정답, 같은 δ를 사용하며, 원본 순서도 동일하게 유지한다.

평가 입력은 총 4,792개지만, 서로 다른 원본 이미지는 2,396개다.

7.1. Aligned Accuracy

모든 validation 이미지를 aligned 색상으로 만들었을 때의 정확도다.
Aligned Accuracy = aligned 조건에서 정답을 맞힌 원본 수 / 전체 원본 수

7.2. Conflict Accuracy

모든 validation 이미지에 반대 색상을 적용했을 때의 정확도다.
Conflict Accuracy = conflict 조건에서 정답을 맞힌 원본 수 / 전체 원본 수

이 값은 학습 시의 색상 관계가 뒤집혔을 때도 숫자를 제대로 분류하는지 보여준다.

7.3. Neutral Accuracy

현재 실험에서는 두 색상 조건 정확도의 평균으로 정의한다.
Neutral Accuracy = (Aligned Accuracy + Conflict Accuracy) / 2

각 원본 이미지에 두 색상을 모두 적용하므로, 색상과 정답의 관계를 균형 있게 만든 평가에 해당한다.

이 지표는 중립 데이터로 학습한 모델의 정확도를 의미하지 않는다. 편향 데이터로 학습한 동일한 모델을 평가한 값이다.

7.4. Shortcut Gap

Shortcut Gap = Aligned Accuracy - Conflict Accuracy

두 조건 사이의 성능 차이를 나타낸다. 정확도를 백분율로 표기할 때 차이의 단위는 %p다.

7.5. Flip Rate

Flip Rate = 색을 바꿨을 때 예측 클래스가 바뀐 원본 수 / 전체 원본 수

정답 여부와 관계없이, 동일한 숫자의 색상 변경에 모델의 예측이 얼마나 민감한지를 측정한다.

Shortcut Gap과 Flip Rate는 정의가 서로 다르다. 현재 결과에서는 aligned 정확도가 100%인 이진 분류 상황이므로 두 값이 같게 나타난다.

8. 현재까지 확보한 주요 결과
============================================================

현재 BinarySmallCNN을 p=0.99 데이터로 1 epoch 학습한 주요 파일럿 결과는 다음과 같다.
- Train Loss: 0.097051
- Train Accuracy: 98.6752%
- Aligned Accuracy: 100.0000%
- Conflict Accuracy: 0.1669%
- Neutral Accuracy: 50.0835%
- Shortcut Gap: 99.8331%p
- Flip Rate: 99.8331%

원본 이미지 수로 설명하면 다음과 같다.
- Aligned 조건: 2,396개 모두 정답
- Conflict 조건: 2,396개 중 4개 정답
- 색상 변경 시 예측이 달라진 원본: 2,392개

이 결과는 현재 설정에서 모델의 예측이 색상에 매우 강하게 의존한다는 증거다.

학습 시 주로 나타난 색상 관계를 유지하면 높은 성능을 보이지만, 숫자 모양을 유지한 채 색을 바꾸면 정확도가 거의 0%로 떨어진다. 따라서 높은 학습 정확도와 aligned 정확도만으로 색상 변화에도 안정적인 숫자 인식을 학습했다고 판단하기 어렵다.

다만 다음과 같은 표현은 피해야 한다.
- “모델이 모양 정보를 전혀 학습하지 않았다.”
- “모든 CNN은 항상 색상만 학습한다.”
- “1 epoch보다 짧은 어느 시점에 색상 의존성이 완성되었다.”
- “이러한 편향은 이후 학습으로 회복할 수 없다.”

현재 결과는 모델의 출력에서 강한 색상 의존성을 보여주지만, 내부 표현에 어떤 정보가 저장되어 있는지, 다른 조건에서도 같은 현상이 나타나는지까지 입증하지는 않는다.

같은 seed와 설정을 사용한 파일럿 결과가 네 실행 폴더에 저장되어 있고, 지표는 동일하다. 이는 해당 설정에서 반복 실행 결과가 일치했다는 근거지만, 서로 다른 seed를 이용한 독립 반복 실험은 아니다.

9. 이전 모델 결과와 구분할 사항
============================================================

프로젝트에는 분류기 부분이 다음과 같은 이전 모델의 결과도 남아 있다.
1,568 → 64 → 2

현재 모델의 분류기는 다음과 같다.
1,568 → 2

이전 구조의 저장 결과는 다음과 같다.
- Train Accuracy: 약 98.3413%
- Aligned Accuracy: 100%
- Conflict Accuracy: 약 2.5876%
- Neutral Accuracy: 약 51.2938%
- Shortcut Gap: 약 97.4124%p
- Flip Rate: 약 97.4124%

이전 구조에서도 강한 색상 의존성이 관측되었다.

다만 현재 연구를 설명할 때 주요 결과는 BinarySmallCNN 기준으로 제시하고, 이전 모델은 별도 참고 결과로 구분해야 한다. 단일 설정의 결과만으로 모델 구조에 따른 차이가 통계적으로 확립되었다고 주장하면 안 된다.

두 구조의 checkpoint는 직접 호환되지 않는다.

10. 구현 및 저장 상태
============================================================

현재 주요 파일의 역할은 다음과 같다.
- dataset.py: 숫자 3·8 필터링, 분할, 색상 생성, 편향·중립 배정, 시각화와 검증
- model.py: BinarySmallCNN 및 10클래스 SmallCNN 정의
- train.py: 1 epoch 학습과 이진 색상 조건 평가
- pilot.py: 편향 데이터 1 epoch 파일럿 실행과 결과 저장
- train_cnn.py: epoch 수를 지정할 수 있는 학습 실행
- validate_dataset.py: 데이터 분포와 시각화 확인
- metrics.py: Shortcut Gap 및 회복 판정 보조 함수
- colored_MNIST.py: 초기 10클래스 Colored MNIST 구현
- example_CNN.py: 일반 흑백 MNIST CNN 예제

파일럿 실행에서는 다음 정보를 저장한다.
- 모델 가중치
- Optimizer 상태
- 학습 및 평가 설정
- Train·validation 원본 인덱스
- 편향·중립 색상 배정
- 원본 이미지별 Hue offset
- Validation aligned·conflict 색상 배정
- JSON 및 CSV 평가 결과

실행별로 새 폴더를 만들어 기존 결과를 보존한다.

데이터 시각화로는 편향 표본, 편향·중립 분포 heatmap, 동일 원본의 두 색상 비교 이미지가 저장되어 있다.

11. 아직 수행하지 않은 연구와 후속 검증 과제
============================================================

현재 확인된 주요 실험은 단일 seed, p=0.99, 1 epoch의 편향 노출 파일럿이다.

다음 항목은 후속 연구에서 검증할 과제이며, 완료된 결과로 서술하지 말아줘.

11.1. 중립 학습 기준 모델

처음부터 중립 데이터로 학습한 모델의 성능을 측정하면, 색상 편향이 없는 조건에서 얻을 수 있는 기준 성능을 설정할 수 있다.

현재 그 기준 성능은 확보되어 있지 않다.

11.2. 편향 학습 이후 회복

편향 데이터로 학습한 모델을 중립 데이터로 추가 학습시키고 다음 변화를 추적할 수 있다.
- Conflict Accuracy의 증가
- Neutral Accuracy의 증가
- Shortcut Gap의 감소
- Flip Rate의 감소

현재 metrics.py에는 다음 회복 판정 기준이 구현되어 있다.
Shortcut Gap ≤ 0.05
그리고
Neutral Accuracy ≥ 기준 모델 정확도 × 0.95

두 조건을 처음 만족하는 회복 epoch를 찾는 함수도 있다.

그러나 실제 회복 학습과 기준 모델 측정은 아직 수행되지 않았다. 이 기준은 현재 코드의 판정 규칙이며, 검증된 연구 결론이나 확정된 최종 기준으로 제시하지 말아줘.

후속 설계에서는 signed gap이 음수가 되는 경우의 처리와, 한 번의 기준 충족만으로 회복을 판정할지 여부도 검토할 수 있다.

11.3. 편향 노출 기간의 영향

편향 데이터로 학습하는 기간을 달리했을 때, 이후 중립 학습에서 회복 속도에 차이가 생기는지 확인할 수 있다.

다만 현재 결과만으로 “편향에 오래 노출될수록 회복이 더 어렵다”고 결론 내릴 수는 없다.

11.4. 편향 강도와 seed 반복

p 값을 달리한 실험과 서로 다른 seed의 반복 실험을 통해, 현재 현상이 어떤 범위에서 재현되는지 확인할 필요가 있다.

11.5. 모델과 과제 범위 확장

현재 두 모델 구조를 같은 실험 절차로 반복 비교하거나, 초기 0~9 분류 설정으로 확장할 수 있다. 이러한 비교·확장 실험은 현재 파일럿 결과와 구분해서 다뤄야 한다.

12. 이 연구를 설명할 때의 요청 사항
============================================================

위 내용을 바탕으로 연구를 설명할 때는 다음을 지켜줘.

1) 먼저 연구의 핵심 질문을 쉬운 말로 설명해줘.
2) 색상이 정답을 바꾸지 않는데도 높은 예측력을 갖도록 설계한 이유를 설명해줘.
3) 동일 원본의 색상만 바꾸는 평가가 무엇을 확인하는지 설명해줘.
4) Aligned Accuracy, Conflict Accuracy, Neutral Accuracy, Shortcut Gap, Flip Rate의 차이를 분명하게 설명해줘.
5) 실제 결과는 현재 BinarySmallCNN의 수치를 우선 사용해줘.
6) 관측된 사실과 그에 대한 해석을 구분해줘.
7) 같은 seed의 반복 실행을 여러 seed의 독립 반복 실험으로 표현하지 마.
8) 중립 데이터 생성, 중립 평가, 중립 데이터 학습을 혼동하지 마.
9) 현재 단계는 색상 의존성을 확인한 파일럿 단계이며, 회복 연구는 후속 검증이 필요한 상태임을 밝혀줘.
10) 추가 정보가 필요하면 자료에 없는 부분을 명시하고, 연구 동기나 결과를 임의로 만들어내지 마.

연구의 현재 상태는 다음 문장으로 요약할 수 있다.

“숫자와 색상이 약 99% 일치하도록 구성한 3·8 Colored MNIST에서 소형 CNN을 1 epoch 학습한 결과, aligned 정확도는 100%였지만 동일한 원본의 색상을 반대로 바꾸면 정확도가 약 0.17%로 감소했고, 약 99.83%의 원본에서 예측이 바뀌었다. 이는 현재 실험 조건에서 매우 강한 색상 의존성이 형성되었음을 보여준다. 중립 데이터에 의한 회복과 편향 노출 기간의 영향은 아직 검증하지 않았다.”
